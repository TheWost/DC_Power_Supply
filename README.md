# DC Power Supply Controller

A Python-based Command-Line Interface (CLI) and Terminal User Interface (TUI) for controlling and monitoring programmable DC Power Supplies via SCPI (Standard Commands for Programmable Instruments).

---

## Features

* **Dual Interface**:
  * **TUI Mode**: Rich, interactive terminal dashboard for real-time monitoring and dynamic adjustments.
  * **CLI Mode**: Fast, single-command execution ideal for automation scripts and quick controls.
* **Core Functions**:
  * Set voltage, current limit, and toggle output channels.
  * Live telemetry for actual output voltage, current, and power draw.
